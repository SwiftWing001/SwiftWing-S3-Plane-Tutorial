# 设备结构检查

## 飞行前检查

* 注意检查尾翼固定螺丝是否上紧，若未上紧，建议及时紧固，避免飞行中出现事故

![1769583272037](image/设备结构检查/1769583272037.png)

* 注意尾翼限位是否卡好，若未卡好，建议及时检查，避免飞行中出现事故

![1769583207143](image/设备结构检查/1769583207143.png)

* 注意舵机臂是否开裂或滑丝，若存在，建议及时修复，避免飞行中出现事故

![1775126493880](image/设备结构检查/1775126493880.png)

* 注意机翼固定螺丝是否上紧，若未上紧，建议及时紧固，避免飞行中出现事故

![1775126647577](image/设备结构检查/1775126647577.png)
